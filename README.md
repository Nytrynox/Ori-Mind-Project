# OriMind

Interactive 3D mental health and meditation platform with guided breathing exercises, ambient soundscapes, and mood tracking.

## Features

- 3D visualization for guided meditation
- Breathing exercise timer with visual feedback
- Ambient soundscape generator
- Daily mood tracking and journaling
- Progress analytics over time

## Tech Stack

HTML, CSS, JavaScript, Canvas API, Web Audio API

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/karthik-idikuda/Ori-Mind-Project.git
cd Ori-Mind-Project
Open index.html in a browser.
```

### Usage

```bash
Open index.html in any modern browser.
```
